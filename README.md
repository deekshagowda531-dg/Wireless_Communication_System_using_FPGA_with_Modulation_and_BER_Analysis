An end-to-end wireless communication system is implemented using two Spartan-3 FPGA boards and two SX1278 LoRa transceivers. The transmitter FPGA generates predefined binary data, which is programmed using Verilog HDL and formatted into packets for transmission. The data is transferred from the FPGA to the SX1278 LoRa transceiver through the Serial Peripheral Interface (SPI). The SX1278 performs LoRa modulation and wireless transmission at 433 MHz. At the receiver, the second SX1278 receives the transmitted data and stores it in its FIFO. The receiver FPGA reads the received data through SPI and compares it with the corresponding predefined transmitted data to identify bit errors and calculate the Bit Error Rate (BER). A Finite State Machine (FSM) is used to control the transmission and reception operations. An LCD display is interfaced with the receiver FPGA to display the received data and BER calculation results. The system is implemented using Verilog HDL and Xilinx ISE. The calculated BER represents the recovered application-payload bit errors after LoRa demodulation rather than the internal physical-layer BER of the LoRa transceiver. The developed system provides a practical FPGA-based platform for wireless data transmission and performance evaluation using BER analysis.
